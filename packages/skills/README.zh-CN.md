## agent-wechat

本 Skill 用于让 AI 智能体通过原生的 `wx` CLI 与后台守护进程与微信进行交互。支持智能体发送与撤回消息（文本、图片、文件、视频、语音、分享卡片）、管理群聊、检索联系人、查看历史会话及执行环境健康自检。

### 安装方法

在支持 Skill 的 AI 助手对话框中输入以下提示词进行安装：

```text
install skill agent-wechat from github repo: https://github.com/atorber/agent-wechat.git skill name is agent-wechat
```
