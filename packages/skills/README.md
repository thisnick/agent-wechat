## agent-wechat

This skill allows AI agents to interact with WeChat via the native `wx` CLI and daemon. It enables sending and recalling messages (text, images, files, videos, voice, link cards), managing group chats, searching contacts, inspecting history, and running environment diagnostics.

### Installation

Install it by providing the following prompt to your AI coding assistant:

```text
install skill agent-wechat from github repo: https://github.com/atorber/agent-wechat.git skill name is agent-wechat
```
