# Soft pair

`AgentWechatSoftPair.wav` is an original synthesized notification chime, selected
for AgentWechat. It contains no recorded or third-party audio samples. The
360 ms WAV uses mono 48 kHz, 16-bit PCM with a peak level of about -13 dBFS.

macOS includes it at the app bundle's resource root. Linux sends its installed
path to the notification service. Windows uses its native default notification
sound. The app does not play a second audio stream over the native notification.
