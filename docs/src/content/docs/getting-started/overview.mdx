---
title: What is agent-wechat?
description: A standalone native WeChat daemon, CLI and OpenClaw channel.
---

agent-wechat communicates directly with WeChat and uses supported official-format local profiles. The Rust `wx` executable is both the CLI and server: `wx serve` runs an authenticated daemon; other CLI invocations, OpenClaw and custom clients use its account-scoped HTTP/SSE API.

No official executable or desktop runs inside the daemon. The initial workflow takes over a stopped existing official Linux profile, preserves its account/device identity and continues supported database and media writes in place. Keep the official app closed while the daemon owns these files.

Supported workflows include native login, saved-device recovery, QR approval, local history, incoming sync, contact/group/roster/avatar lookup, image/file/video/voice retrieval and durable sends. Sync does not return all server history or every thread. Groups have their own catalog and can be looked up without an existing conversation. Whole-thread read marking updates local unread state and reports a native cross-device read boundary.

The distribution targets Linux x64 and ARM64 with glibc 2.36+. Profile compatibility is checked separately from CPU compatibility: unknown database layouts fail explicitly. FTS/search-index maintenance, group creation, sticker sending and large-file branches remain outside this scope. Fresh-profile creation, copy import/export and returning a profile to the official app are experimental extras.
