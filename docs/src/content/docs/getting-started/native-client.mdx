---
title: Native Client Scope
description: Supported profile takeover and remaining compatibility limits.
---

The native daemon is the main runtime. Its initial supported workflow is taking over a stopped existing official Linux profile and continuing supported writes. It does not need the official executable at runtime. A compatible profile, valid account authorization and exclusive ownership are separate requirements.

Native credentials may expire or be rejected by WeChat. The daemon validates active authorization, performs bounded renewal and can recover through saved-device trust. A reusable saved login may avoid a QR but does not guarantee permanent authorization. Background connect never silently starts a QR challenge. Explicit logout persists an inhibition fence so restarting cannot silently reconnect.

Supported encrypted database writers cover messages, contact/group metadata, local desktop reads and supported image/voice/file/video caches and resource joins. Unknown sync commands remain durably staged and block a complete official projected cursor. Unknown files are preserved. Official FTS/search indexes and arbitrary profile migrations are not maintained.

Controlled x64 test-account validation covered saved-file login without QR, existing encrypted history, cold restarts, incoming image qualities and both normal/original video, all four outgoing media kinds, contacts/groups/rosters/avatars, local writeback and logout invalidation. The account owner confirmed file/image opening and video/voice playback. CI separately checks native x64/ARM64 executables with synthetic protocol/profile data; live ARM64 account use, arbitrary official builds, multi-account live use and multi-chunk voice playback are not established by those fixtures.

Fresh-profile initialization, copy import/export and returning a native-written profile to the official app remain experimental extras. The main runtime is no longer labeled experimental as a whole. See the repository's [capability checklist](https://github.com/thisnick/agent-wechat/blob/main/packages/native-client-rust/FEATURES.md) for evidence and limits.
