:::note[Container backend]
This page describes the retained official-client container backend and `wx-legacy`. The experimental standalone `wx` daemon has a separate [native client guide](/getting-started/native-client/), configuration and versioned API.
:::

The `wx-legacy` CLI lets you manage the agent-wechat container and interact with WeChat from your terminal.

## Install

```bash
AGENT_WECHAT_SKIP_NATIVE_INSTALL=1 npm install -g @agent-wechat/cli
```

This installs the `wx-legacy` command globally.

## Prerequisites

- **Node.js >= 24.16**
- **Docker** installed and running

## Verify installation

```bash
wx-legacy --version
```

## Configuration

The CLI reads configuration from:

| Source | Description |
|--------|-------------|
| `AGENT_WECHAT_URL` | Server URL (default: `http://localhost:6174`) |
| `AGENT_WECHAT_TOKEN` | Auth token (overrides token file) |
| `~/.config/agent-wechat/token` | Auto-generated auth token (created on first `wx-legacy up`) |

The auth token is generated automatically on first run and shared with the container via a read-only volume mount.

## Global options

| Option | Description |
|--------|-------------|
| `-V, --version` | Show version |
| `-h, --help` | Show help |
