:::note[Container backend]
This page describes the retained official-client container backend and `wx-legacy`. The experimental standalone `wx` daemon has a separate [native client guide](/getting-started/native-client/), configuration and versioned API.
:::

## Container

| Command | Description |
|---------|-------------|
| `wx-legacy up [--proxy user:pass@host:port]` | Start the agent-wechat container (auto-pulls image) |
| `wx-legacy down` | Stop and remove the container |
| `wx-legacy logs` | Tail container logs |
| `wx-legacy status` | Show container up/down status and login status |

## Auth

| Command | Description |
|---------|-------------|
| `wx-legacy auth login` | Log in to WeChat (shows QR code in terminal) |
| `wx-legacy auth logout` | Log out of WeChat |
| `wx-legacy auth status` | Check login status |
| `wx-legacy auth token` | Show current auth token |
| `wx-legacy auth token --regenerate` | Generate a new auth token |

Login options:
- `--timeout <seconds>` — login timeout (default: 300)
- `--new` — switch to a new account instead of reusing the existing session

## Chats

| Command | Description |
|---------|-------------|
| `wx-legacy chats list` | List chats from WeChat |
| `wx-legacy chats get <chatId>` | Get details for a specific chat |
| `wx-legacy chats find <name>` | Search chats by display name |
| `wx-legacy chats open <chatId>` | Open a chat in the WeChat UI |

Options: `--limit <n>`, `--offset <n>`, `--json`

## Messages

| Command | Description |
|---------|-------------|
| `wx-legacy messages list <chatId>` | List messages in a chat |
| `wx-legacy messages send <chatId>` | Send a message |
| `wx-legacy messages media <chatId> <localId>` | Download a media attachment |

Send options:
- `--text "message"` — send text
- `--image photo.jpg` — send an image
- `--file document.pdf` — send a file

Media options:
- `--output <path>` — save to a specific file path
- `--best` — save the best available image (the default)
- `--full` — require the original-resolution image
- `--thumbnail` — save the cached image preview

The media command does not open a chat. For a regular phone photo, run
`wx-legacy chats open <chatId>` first if you want WeChat to cache the standard-size
copy; otherwise the default media command may save only the thumbnail.

## Debug

| Command | Description |
|---------|-------------|
| `wx-legacy screenshot [file]` | Save a screenshot (default: `screenshot.png`) |
| `wx-legacy a11y` | Dump the accessibility tree (`--format json\|aria`) |
