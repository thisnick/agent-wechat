Send a text reply with a reference to a message saved in the same chat. Your token needs both `read` and `send` permission.

1. Find the original with `wx messages list CHAT_ID`. Copy its `id` and `serverId` exactly; both are strings.
2. Send your reply with both quote flags:

   ```bash
   wx messages send CHAT_ID --text "Agreed" \
     --quote-message-id MESSAGE_ID --quote-server-id SERVER_ID --detach
   ```

   The returned JSON includes a send `id`, its `state` and a local `receiptPath`. For example, a newly queued send includes `"state":"queued"`. Check it with `wx messages sends get SEND_ID`.

The daemon verifies the source IDs against the original in its history. A source from another chat, a changed server ID, a recalled message or an unavailable original returns an error before submission. Keep the same idempotency key when checking or repeating the original request; changing either quote ID conflicts with that send.

## API and SDK

Post this body to `/v1/accounts/ACCOUNT/sends`, with your bearer token and an `Idempotency-Key` header:

```json
{
  "kind": "text",
  "threadId": "CHAT_ID",
  "text": "Agreed",
  "quote": { "messageId": "MESSAGE_ID", "serverId": "SERVER_ID" }
}
```

Supply only the source IDs. The daemon prepares its content and sender metadata from the saved original. In the TypeScript SDK, add the reference as the final optional argument:

```ts
await client.sendText(accountId, threadId, "Agreed", key, { messageId, serverId });
```

## Supported originals

| Original | Availability |
| --- | --- |
| Text, image, voice or video | Supported saved message forms |
| Shared link or file | Supported app-message forms |
| Existing quoted reply | Uses the immediate reply's comment |
| Sticker, forwarded history, system or unknown message | Rejected |

<Aside title="Good to know">
- Live server acceptance and recipient rendering remain unverified. Current coverage comes from static analysis and offline tests.
- The reply must contain non-whitespace text and fit within 16 KiB of UTF-8. The complete escaped message has a separate 256 KiB limit; large originals can be rejected.
- Only text replies accept a quote. Attachment and shared-link sends reject `quote`.
- The original must be locally available before the first submission. A saved send receipt lets an identical retry use its original reference without reading a changed source again.
- A quoted reference does not establish that the recipient can download or play the original media.
</Aside>
