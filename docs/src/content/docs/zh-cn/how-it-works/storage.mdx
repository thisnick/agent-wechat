```text
~/.config/agent-wechat/
├── server/config.toml              服务端配置 (可选)
└── client.toml                     CLI 客户端：已保存的服务器列表与默认账号
~/.local/share/agent-wechat/        核心数据目录
├── api-token                       管理员所有者 API 访问令牌
└── accounts/<id>/
    ├── profile/                    微信原生数据目录：聊天记录、联系人、媒体缓存
    └── agent/                      Daemon 专有数据：登录凭据、任务队列、事件日志
$TMPDIR                             离线审查专用临时只读快照
```

在 Windows 上，配置文件位于 `%APPDATA%\agent-wechat`，数据文件位于 `%LOCALAPPDATA%\agent-wechat`。macOS 采用与 Linux 一致的路径标准。

如果你是通过 `--official` 登录的，则不会生成内部的 `profile/` 文件夹：Daemon 会直接使用宿主机上的 Linux 版微信目录（即 `~/xwechat_files` 与 `~/.xwechat`），核心数据目录下仅保留 Daemon 专属的运行时凭证与状态。

## 数据备份方案

先停止 Daemon 服务（执行 `wx daemon stop`、`systemctl --user stop agent-wechat-native` 或 `docker compose stop`），然后打包备份数据目录：

```bash
tar -czf wechat-backup.tgz -C ~ .local/share/agent-wechat
```

对于使用 `--official` 挂载官方目录的用户，需在打包命令中连同 `xwechat_files .xwechat` 一并备份。仅仅备份 Profile 目录会丢失在途发送记录、OpenClaw 处理位点以及撤回标记；仅仅备份数据目录则没有任何聊天历史记录。

## 修改数据路径

可以在 `~/.config/agent-wechat/server/config.toml` 中配置 `dataDir`，或在启动命令中显式传递 `--data-dir` 参数。详见[配置选项](/zh-cn/reference/configuration/)。

<Aside title="使用提示">
- **运行中的 Daemon 直接并发只读访问其掌控的 Profile。** 它复用只读数据库连接与轻量事务。离线数据审查会创建独立的数据库私有快照（单库最多 2 GiB，总体最多 8 GiB），请确保 `$TMPDIR` 所在磁盘分区空间充足，且严禁将临时目录直接指向 Profile 目录。
- **未知格式的 Profile 绝不擅自修改。** Daemon 在向数据库写入前会严格检验其 schema 表结构，一旦发现未适配的未知版本将立即熔断拒绝写入。建议备份数据并等待官方更新，切勿强行覆盖。
- **损坏的数据库文件会完整保留。** 若 Daemon 自身的数据库发生校验异常，系统会完整保留原始文件并生成一份灾后修复副本作比对存证。
- **升级 `wx` 二进制程序绝不会自动清除数据。** 但注意回滚旧版本二进制文件无法逆向撤销已执行的高版本数据迁移，因此在重大升级前请务必留存冷备份。
- **消息撤回标记保存在数据目录下。** 单独导出 Profile 目录并不包含撤回的审计元数据。
- OpenClaw 将消费进度存储在 `consumerStateDir` 中，该目录同样需要纳入定期备份范围。
</Aside>
