<Steps>

1. **运行 `wx auth login`。**

   在终端中，`wx auth login` 会引导你完成首次设置：
   - 如果本地没有正在运行的 Daemon，它会询问是否以后台方式启动。
   - 如果还没有账号，它会让你创建新 Profile；在 Linux 上，如果存在 `~/xwechat_files`，确认备份后也可以接入现有的 Linux 版微信文件。

   ```bash
   wx auth login
   ```

   对于脚本或非交互式终端，请直接执行以下步骤：

   <Tabs>
   <TabItem label="全新 Profile">

   适用于所有平台。agent-wechat 会在其独立的数据目录中创建一个全新的微信 Profile。

   ```bash
   wx daemon start
   wx accounts create --alias me
   wx auth login
   ```

   </TabItem>
   <TabItem label="现有微信数据（Linux）">

   使用 Linux 版微信的原有文件，保留聊天记录。请先退出微信并做好备份：

   ```bash
   wx daemon start
   tar -czf ~/wechat-profile-backup.tgz -C ~ xwechat_files .xwechat
   wx auth login --official
   ```

   `--official` 会在你的家目录中查找文件。如果文件位于其他位置，请传入包含这些文件的目录：`--official=/path/to/home`。

   </TabItem>
   </Tabs>

2. **用手机微信扫描二维码。** 终端提示正在等待确认时，在微信中确认登录。

   使用 `wx --json auth login` 时，等待确认的提示会以 JSON 行的形式输出到 stderr，其中包含 `event: "login.progress"` 和 `state: "awaiting_approval"`。最终的操作结果则是一个完整的 JSON 文档，输出到 stdout。

   <img src={qrLogin.src} class="mock wide" alt="终端中运行 wx auth login 打印二维码，随后确认登录" />

3. **检查是否成功。**

   ```bash
   wx messages list filehelper --limit 1
   ```


</Steps>

连接完成！接下来，可以让 Daemon [在后台持续运行](/setup/run/)，然后通过 [CLI](/use/cli/)、[OpenClaw](/openclaw/setup/) 或[你自己的代码](/use/api/)使用它。

## 退出登录或删除 Profile \{#sign-out-or-remove-a-profile}

使用 `wx accounts list` 列出 Profile，并使用返回结果中的账号 ID：

```bash
wx --account ACCOUNT_ID auth login
wx --account ACCOUNT_ID auth logout
```

使用 `wx --account ACCOUNT_ID auth logout --local` 可以在 Daemon 本地退出登录，并保留已保存的登录凭据，不会向微信发送退出请求。两种方式都会停止自动重连。

退出登录完成后，请重复输入完整的账号 ID，从 Hub 中移除该 Profile：

```bash
wx accounts remove ACCOUNT_ID --confirm ACCOUNT_ID
```

```json
{ "accountId": "ACCOUNT_ID", "removed": true, "filesRetained": true }
```

移除操作会注销该 Profile，并保留其本地文件。`wx auth forget --yes` 是另一项独立操作，用于删除已保存的登录凭据；它不会移除 Profile。

<Aside title="注意事项">
- **新 Profile 不包含旧的聊天记录。** 微信不会向新登录下发完整的历史消息，因此新 Profile 只会从登录之后的新消息开始记录。
- **使用 `--official` 时，Daemon 运行期间请勿打开官方微信。** 两者同时写入同一批文件可能导致数据损坏。
- **账号必须一致。** 使用 `--official` 时，请用这些文件所属的微信账号登录；Daemon 不会把其他账号的消息写入这些文件。
- **正在使用 AgentWechat 桌面应用？** 其内置的 Hub 使用相同的默认端口（`127.0.0.1:6174`）。请在 **设置 → 导出 CLI 密钥** 中导出密钥，而不要另外启动一个 Daemon。
- **下次启动 Daemon 时会自动重连。** 只有微信结束登录会话后，才需要重新登录。
- **没有终端界面？** `wx` 会把二维码保存为 PNG 图片，并打印图片路径。
- **手机确认一直没有反应？** 某些确认流程需要手机通过局域网访问 Daemon（端口 8050 至 8100）。请检查防火墙和 Wi-Fi 的客户端隔离设置。
- **多个账号：** 分别创建并登录每个账号，然后使用 `--account ALIAS` 或 `wx accounts select ALIAS` 选择要操作的账号。
</Aside>
