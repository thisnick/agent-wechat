---
title: Architecture
description: Native protocol, official files, durable sidecars and client boundaries.
---

`wx serve` composes independent Rust libraries: configuration, protected sidecar store, official-profile reader/writers, protocol/crypto, serialized account workers and the HTTP/SSE API. The same executable supplies the command-line client. It communicates directly with WeChat; the official app is needed only to supply an existing supported profile for the initial takeover workflow.

Each account has its own identity, credentials, mutation guard, worker, sync state and event journal. One daemon can host independent accounts. Native ownership leases protect cooperating clients; the official app must also be stopped explicitly. Authorization must match the stored username, UIN, device and all encrypted databases.

The official profile contains history, metadata, desktop read state and supported media caches. Native sidecars hold protected credentials, original sync commands, projection journals, outbox/jobs and independent consumer receipts. Received sync and successful projection are separate checkpoints. Unsupported commands are retained; a complete official cursor cannot advance over them.

Heartbeat/NewSync polling detects incoming work. Durable message commits produce account events and replayable SSE. An event acknowledgement confirms consumer custody, not message read state. HTTP disconnects do not undo submitted durable jobs. Sending uses idempotency keys and preserves uncertain outcomes so a lost response does not cause an automatic duplicate.

OpenClaw either owns a native child or connects to an external daemon. It stores event custody before acknowledgement, applies access/mention policy before media retrieval, and confirms exact prepared model input before sparse local read projection. It never downloads a runtime at plugin startup.
