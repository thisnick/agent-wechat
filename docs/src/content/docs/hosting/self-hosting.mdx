---
title: Self-Hosting
description: Choose one owner for the native daemon.
---

Start the native daemon directly:

```bash
wx serve --server-config /absolute/server/config.toml
```

Or use its verified background process manager:

```bash
wx daemon start
wx daemon status
wx daemon logs --follow
wx daemon stop
```

Stopping preserves history and reusable saved login; it does not submit logout. Pick exactly one owner: foreground, `wx daemon`, systemd, Compose or OpenClaw managed mode. OpenClaw external mode connects to any independently owned daemon.

The optional `deploy/native/agent-wechat-native.service` is a systemd **user** unit running `wx serve` from `~/.local/bin/wx`. It provides user-session lifecycle, restart handling and restrictive filesystem access. It is not installed/enabled automatically. Provision the executable, private settings/token/data paths, and explicitly add any attached official profile to its allowed write paths before a deliberate deployment. Validation checks unit syntax without starting it.

For a container, follow [Docker Compose](/hosting/docker-compose/). Server settings and data are described under [storage](/operations/data/). Both the official profile and native sidecars belong in backups. Exposing the API, starting a service or changing account ownership are deployment operations; a successful build does not perform them.
