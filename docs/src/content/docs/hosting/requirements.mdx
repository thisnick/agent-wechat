---
title: Requirements
description: Native host, supported profile and media dependencies.
---

The native runtime targets Linux x64 or ARM64 with glibc 2.36+. Direct source builds use Rust 1.93.1 and a C compiler; release builds use Bookworm in CI. The npm launcher needs Node 24.16+. The standalone executable needs neither Node nor Docker. OpenClaw integration is validated against OpenClaw 2026.10.2.

Initial account setup needs a complete, supported existing official Linux profile, a stopped official app, legitimate read/write permissions and the matching WeChat account. Saved-device trust may skip QR scanning; phone approval or a fresh QR may still be needed. An empty sidecar directory does not create a supported fresh official account store.

Provide persistent disk for the official profile and native `dataDir`, plus private scratch capacity for consistent read snapshots. A database snapshot is bounded at 2 GiB per database and 8 GiB total; allow additional headroom for concurrent accounts and SQLite work. No fixed memory estimate substitutes for workload testing.

FFmpeg decodes incoming WXGF still previews; FFmpeg and FFprobe normalize outbound audio/video sources. The runtime image includes both tools; direct installs must make them available on the daemon's PATH for those operations. SILK voice encoding is compiled from the bundled public sources and does not use the official binary. No GUI, ptrace capability, unconfined seccomp or Docker socket is needed by the native service.

The daemon binds loopback. For other hosts, use verified HTTPS through a reverse proxy or an authenticated encrypted tunnel. Outbound native proxy configuration is not implemented in this release.
