---
title: Native HTTP API
description: Account-scoped v1 resources, jobs, events and media.
---

The native API is versioned under `/v1`. Except the minimal `/health` liveness endpoint, requests require bearer authentication and appropriate account scopes. Use lossless decimal-string IDs and opaque server-issued cursors. The Rust contracts generate the private TypeScript SDK; a route alone is not evidence of a successful network operation.

| Surface | Routes / behavior |
| --- | --- |
| Runtime/account status | `GET /v1/status`, `GET /v1/accounts`, `GET /v1/accounts/{account}`, account `/capabilities` |
| Official profile selection | `POST /v1/profiles/official`; prepares in-place identity-bound ownership before login |
| Login | Account `POST /login-attempts`, `GET /login-attempts/{id}`, `GET /login-attempts/{id}/qr`, `POST /login-attempts/{id}/cancel` |
| Lifecycle | Account `POST /connect`, `/disconnect`, `/logout`, `/forget-credentials`; persistent logout/forget fences |
| Catalog/history | Account `GET /threads`, `/contacts`, `/groups`, `/groups/{id}/members`, `/threads/{id}/messages`, `/messages/{id}` |
| Exact metadata | Account `POST /contacts/lookup`, `GET /groups/{id}/lookup`; refresh/sync operations retain their own checkpoints |
| Sends | Account `POST /sends`, `GET /sends/{id}`, `GET /sends/by-idempotency-key`, `POST /sends/{id}/cancel` |
| Media | Account `POST /uploads`, message `GET /media`, `POST /media-transfers`, asset `GET /media/{id}/content` |
| Durable jobs | Account `GET /jobs/{id}`, `POST /jobs/{id}/cancel`, `/retry`, `POST /media-writeback/repair` |
| Local reads | Account `POST /threads/{id}/read-state`; expected-version checking and exact sparse IDs or explicit human through-boundary |
| Events | Account `GET /events`, `GET /events/stream`, `POST /consumers/{consumer}/ack` |
| Access tokens | `GET/POST /v1/access-tokens`, `DELETE /v1/access-tokens/{id}`; owner/admin permissions |

Paths containing placeholders must be URL encoded. A send/upload/login response retains a durable identity before asynchronous work; use idempotency and inspect the same resource after a lost response. `needs_review`, partial voice receipts and confirmed expiry must not trigger blind retries. Native acceptance does not prove recipient delivery/playback.

Media separates advertised variants from verified cached bytes and returns pending/expired/unsupported states explicitly. Cached content supports bounded byte ranges and integrity/length checks. Cached bytes can outlive remote expiry. HTTP cancellation closes streaming without cancelling already submitted jobs.

Resource cursors bind the account, query and retained view; an expired cursor requires an explicit new view. Tombstones preserve deleted positions. SSE supports journal replay, bounded retention and gap reporting. Persist custody before acknowledgement. Consumer acknowledgements never change unread state; desktop read state also does not synchronize the phone's read state.

See the [CLI workflows](/getting-started/cli/commands/) and public source contracts in [`wechat-api`](https://github.com/thisnick/agent-wechat/tree/main/packages/native-client-rust/crates/wechat-api). The old container `/api` and UI operations are removed.
