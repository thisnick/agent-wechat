---
title: Calling
description: Call controls, ownership and audio connections.
---

Check calling availability with `wx calls status`, then use the CLI, OpenClaw or
the control and audio connections described below.

## Check availability

1. In a source build, run `wx calls --help`. The parent command only prints help;
   it does not connect, log in or open audio devices.
2. Run `wx calls status` against your selected daemon. A disabled backend reports
   `capabilities.directAudio: false`. A default build without the call routes
   returns an unavailable route instead.
3. Require the corresponding capability before participating. An API route or a
   configured plugin does not make a call available.

Source builds use `native-calls` for the daemon's native worker and `call-audio`
for the CLI's local audio adapter. These are separate features: a headless daemon
does not need access to a microphone or speaker.

## API connections

All paths below begin with `/v1/accounts/{account}`. Authenticate with an
`Authorization: Bearer …` header, including on WebSocket upgrades. Tokens must
never appear in socket URLs. Use HTTPS/WSS or a trusted tunnel for remote access.

| Connection | Purpose | Token scope |
| --- | --- | --- |
| `GET /calls/current` | Read capabilities, current offer and busy state | `calls` |
| WebSocket `/calls/socket` | Observe call events and send control commands | `calls` |
| WebSocket `/calls/{callId}/media` | Exchange the owner's PCM audio | `calls`, plus the current owner token |

The control socket starts with `hello` and its current snapshot. Connecting
alone does not answer calls. Send `call.ready` after preparing audio; readiness
can cover outgoing calls, one pending offer, or all calls. Wait for
`call.offered` before answering.

The first successful `call.answer` owns an incoming call; `call.dial` assigns
ownership to its initiator. Other clients see busy state and cannot start another
call. The owner attaches audio using the returned owner token. Observers receive
no audio. Keep the control socket connected; reconnecting alone does not reclaim
ownership. Stale offers and tokens are rejected.

An accepted end command starts termination. Keep both sockets open until the
terminal state arrives. Missing confirmation remains an unknown outcome; inspect
it before dialing again. An unanswered offer also receives an `ended` event when
WeChat confirms it ended or was handled elsewhere.

The server pings control sockets every 15 seconds; clients must reply with Pong.
A silent connection closes after 45 seconds, followed by a five-second ownership
cleanup window. Outgoing calls wait up to one minute for pickup. Connected calls
start termination after one minute without a fresh authenticated peer packet;
malformed or replayed traffic does not reset that timer.

Audio uses PCM16 little-endian samples in versioned binary frames. Follow the
announced format, track and generation. `call.clear_audio` interrupts queued
output. The TypeScript SDK needs no device or codec bindings; its WebSocket
factory must support authentication headers, which browser WebSocket alone cannot
supply.

## CLI and OpenClaw

| Command | Behavior |
| --- | --- |
| `wx calls monitor --json` | Observe events without opening audio devices |
| `wx calls monitor` | Register readiness and show incoming prompts; open audio on acceptance |
| `wx calls dial CONTACT` | Participate using this computer's microphone and speakers |
| `wx calls answer [CALL_ID]` | Answer the current matching offer using local audio |

Interactive participation requires a `call-audio` build. A late answer stays tied
to the selected offer; it must not answer a replacement caller.

OpenClaw calling defaults to off. Configure its separate `inboundAllowFrom`,
`outboundAllowTo` and `outboundToolAllowFrom` lists; messaging permission grants
none of them. The OpenAI response audio bridge streams audio to its provider and
checks readiness before answering. It uses no local microphone. Read-only agent
consultation requires opting into both consultation and the host's per-call
session storage.

:::note[Good to know]
Calling is disabled in the default daemon. The native worker is restricted to an
expiring isolated test. Media security across a call's lifetime and ordinary
microphone/speaker calling still need validation. Video
and conference capabilities remain off.
:::
