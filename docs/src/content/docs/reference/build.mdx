---
title: Build from source
description: Build and test wx, the npm packages and the Docker image yourself.
---

You need Rust 1.93.1 with a C compiler, Node 24.16+ and pnpm 9.15.4. CI builds on Linux, macOS and Windows.

```bash
git clone https://github.com/thisnick/agent-wechat && cd agent-wechat
pnpm install --frozen-lockfile
pnpm native:build        # Rust workspace, including the wx binary
pnpm native:test
pnpm build               # TypeScript packages, OpenClaw plugin and these docs
```

The binary is `packages/native-client-rust/target/debug/wx`. To build the Docker image:

```bash
pnpm build:image         # tags agent-wechat-native:local
```

Release builds, CI and the publishing process are described in [`deploy/native/README.md`](https://github.com/thisnick/agent-wechat/blob/main/deploy/native/README.md). Contributor rules are in [`AGENTS.md`](https://github.com/thisnick/agent-wechat/blob/main/AGENTS.md).

## Try the browser client

1. Start the local simulator and connected browser client:

   ```bash
   pnpm client:dev
   ```

   It prints a local browser URL and the location of its synthetic data.

2. Open the URL, add an account, then use **Simulate scan** and
   **Simulate phone approval**. Chats open automatically after approval.

3. Open **Simulator controls** in a conversation to receive a message, send from
   the simulated phone, or try a rejected or unconfirmed send.

4. Receive an image to see standard quality load automatically. **Download original**
   keeps the full image on the agent-wechat hub; once available, **Save original**
   saves it to your device. Opening a chat clears its unread badge after history
   loads. Scroll up to browse history, then select **Latest messages** to return.

:::note[Good to know]
This source preview uses synthetic accounts and does not connect to WeChat.
Text messaging is available; file sending, desktop packaging and installed-app
setup are still in development. Ctrl+C stops the preview's own processes.
:::
