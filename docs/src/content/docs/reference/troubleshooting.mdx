---
title: Troubleshooting
description: Diagnose native installation, login, profile and media issues.
---

- **No native runtime installed:** install the exact release or use `wx-native-install` after provisioning its matching assets. The launcher never downloads at invocation time. x64/ARM64 GNU targets require glibc 2.36+.
- **Old serverUrl/backend configuration rejected:** follow the [migration guide](/getting-started/migration/). The retired container `/api` is not the native `/v1` API.
- **Owner/listener conflict:** stop the existing intended owner, or use OpenClaw external mode. Never terminate an unrelated process just because it owns a port.
- **Account/database mismatch:** select the profile's account and retain its saved identity/key information. A fresh QR cannot bypass username/UIN/device/database validation. Preserve the source rather than deleting it.
- **QR required/expired:** start explicit login and use its current white PNG. Bounded refresh is distinct from scan/phone approval; a transient poll timeout does not discard an approved challenge.
- **Unsupported schema/projection:** retain the snapshot and unknown commands. Do not reopen the official app concurrently, delete FTS files or manually advance an official cursor over unknown work.
- **Media pending:** inspect the existing durable transfer/job with a bounded retry policy. Explicit expiry is terminal; cached verified bytes can still work. XML is not an attachment.
- **Uncertain send:** inspect the same idempotency key/job and retained receipts. Do not submit a new send to resolve uncertainty.
- **OpenClaw remains unread:** check access gates, prepared model input and the explicit conversation-access hook permission. Event acknowledgement and reply delivery alone do not mark messages read.

CI, fixture checks, live protocol acceptance and recipient playback are distinct evidence. Report the exact runtime version, supported profile layout and redacted status; keep credentials, signed URLs and raw account data private.
