---
title: Conference calls
description: Start or join a group voice call with mixed playback and individual participant levels.
---

Use the CLI's microphone and speakers to participate in a group voice call.
Incoming tracks are mixed for playback, with a separate signal meter for each
verified participant. Video and direct-call promotion are unavailable.

## Start or join

1. Select the daemon and account, then check availability:

   ```sh
   wx calls status
   ```

   Require `conferenceCreate` and `conferenceAudio` to start, or
   `conferenceJoin` and `conferenceAudio` to join.

2. Start a voice call in an existing group with selected contact IDs:

   ```sh
   wx calls conference start GROUP_ID --invite CONTACT_A --invite CONTACT_B
   ```

   Or join a current invitation for that group:

   ```sh
   wx calls conference join GROUP_ID
   ```

   Join fails when there is no current invitation; it never creates a room.
   Keep this terminal open throughout the call.

3. Speak after connection. The interactive view shows measured audio separately
   from membership and microphone state:

   ```text
   Connected. Microphone and mixed speakers active; 2 receive tracks.
   Mic [#######...] -18dB  Speaker [########..] -10dB
   Alice [######....] -24dB joined mic on
   Bob   [..........] -60dB joined mic off
   >
   ```

4. Type a key, then Enter:

   | Key | Action |
   | --- | --- |
   | `m` | Mute/unmute our microphone |
   | `s` | Enable/disable local playback; incoming participant levels still update |
   | `i` | Search saved contacts and choose result numbers to invite |
   | `p` | Show the full participant roster and microphone states |
   | `d` | List local audio devices |
   | `l` or `h` | Leave our participation |
   | `?` | Show help |

   You can also enter `invite CONTACT_ID OTHER_ID`. A submitted invitation
   remains separate from a participant joining. Inviting does not promote a
   direct call.

   After `d`, use `d input NUMBER`, `d output NUMBER`, or `d default` to change
   devices. New devices are prepared while the current ones remain active.
   A switch can briefly interrupt local audio. Type `cancel` to close a picker.

## Watch for invitations

Run `wx calls monitor`. When a conference invitation appears, enter `j NUMBER`
to join that invitation. Leaving returns to watching; standalone start/join
exits. `Ctrl-C` requests cleanup and restores the terminal.

Use `wx calls monitor --json` for passive observation without devices. It never
answers or joins automatically.

:::note[Good to know]
Levels measure digital PCM, not hardware volume. Silence does not prove mute or
departure. Unattributed audio is labeled by track. The speaker meter measures the
mixed playback stream. More participants than fit on screen are summarized;
`p` shows the full roster.

The owning terminal supplies invitation and leave controls. A second client
cannot take over the call. The current native worker limits calls to 20 minutes;
longer calls still need validation. See [Calling](../calls/) for device setup
and the [Calls API](../calls-api/) for ownership and protocol details.
:::
