---
title: Environment Variables
description: Native configuration and installer overrides.
---

| Variable | Purpose |
| --- | --- |
| `XDG_CONFIG_HOME` | Server/client configuration root |
| `XDG_DATA_HOME` | Default daemon durable root |
| `AGENT_WECHAT_SERVER_CONFIG` | Server TOML file |
| `AGENT_WECHAT_DATA_DIR` | Daemon durable-root override |
| `AGENT_WECHAT_CONFIG` | CLI client configuration file |
| `AGENT_WECHAT_SERVER` | Named CLI server selection |
| `AGENT_WECHAT_URL` | Explicit CLI endpoint |
| `AGENT_WECHAT_TOKEN_FILE` | CLI bearer-token file |
| `AGENT_WECHAT_TOKEN` | Explicit CLI bearer token; prefer a protected file |
| `AGENT_WECHAT_ACCOUNT` | CLI account selection |
| `AGENT_WECHAT_NATIVE_BINARY` | Absolute separately provisioned executable for npm launcher |
| `AGENT_WECHAT_NATIVE_ARTIFACT_DIR` | Absolute offline release-assets directory for installer |
| `AGENT_WECHAT_SKIP_NATIVE_INSTALL=1` | Explicitly defer npm native installation |
| `TMPDIR` | Private snapshot/scratch location, never the official profile |

Explicit CLI flags take precedence. Paths are references, not credentials. Do not put token contents in public deployment files. Installer skip/offline overrides do not make unsupported platforms work; normal `wx` invocation never downloads a missing executable.
