title: Keep it running
description: Run the daemon in the background with wx daemon, systemd or Docker Compose.
---

import { Aside, Tabs, TabItem } from '@astrojs/starlight/components';

Pick **one** way to run the daemon. Each one owns the process, so don't combine them.

<Tabs>
<TabItem label="wx daemon">

The simplest option, and the only one that also works on macOS and Windows. It starts `wx serve` in the background for the current user.

```bash
wx daemon start
wx daemon status
wx daemon logs --follow
wx daemon stop
```

</TabItem>
<TabItem label="systemd">

Restarts on failure and starts with your user session. Install the example [user unit](https://github.com/thisnick/agent-wechat/blob/main/deploy/native/agent-wechat-native.service):

```bash
mkdir -p ~/.config/systemd/user ~/.config/agent-wechat/server
curl -fsSLo ~/.config/systemd/user/agent-wechat-native.service \
  https://raw.githubusercontent.com/thisnick/agent-wechat/main/deploy/native/agent-wechat-native.service
test -f ~/.config/agent-wechat/server/config.toml ||
  echo 'schemaVersion = 1' > ~/.config/agent-wechat/server/config.toml
```

Before enabling it, edit the unit:

- `ExecStart=` runs `~/.local/bin/wx`. Change it if `command -v wx` says otherwise.
- `ReadWritePaths=` only allows `~/.local/share/agent-wechat`. Add your profile's folders, for example `%h/xwechat_files %h/.xwechat`.

```bash
systemctl --user daemon-reload
systemctl --user enable --now agent-wechat-native
```

On a headless server, run `loginctl enable-linger` so the service starts without a login.

</TabItem>
<TabItem label="Docker Compose" id="docker-compose">

Start from the example [`compose.yaml`](https://github.com/thisnick/agent-wechat/blob/main/deploy/native/compose.yaml) and [`server.toml`](https://github.com/thisnick/agent-wechat/blob/main/deploy/native/server.toml), then:

1. Set `image:` to `ghcr.io/thisnick/agent-wechat-native:vVERSION` and remove the `build:` section.
2. Create an API token: one copy for your CLI, one owned by the container user (UID 10001).

   ```bash
   umask 077; mkdir -p ~/.config/agent-wechat secrets
   head -c 32 /dev/urandom | base64 > ~/.config/agent-wechat/box-token
   sudo install -m 600 -o 10001 -g 10001 ~/.config/agent-wechat/box-token secrets/api-token
   ```

3. Add your profile to `volumes:`. The source is the folder that contains `xwechat_files` and `.xwechat`:

   ```yaml
   - type: bind
     source: /home/you
     target: /profiles/wechat
   ```

4. Start it, then log in using the path inside the container:

   ```bash
   docker compose up -d
   wx config server add box --url http://127.0.0.1:6174 \
     --token-file ~/.config/agent-wechat/box-token
   wx --server-name box auth login --official=/profiles/wechat
   ```

The container runs as UID 10001, so that user needs write access to the profile.

</TabItem>
</Tabs>

<Aside title="Good to know">
- **Stopping keeps you logged in.** History and saved login survive restarts. Use `wx auth logout` to actually log out.
- **The daemon listens on 127.0.0.1:6174 only.** To reach it from another machine, put it behind an HTTPS reverse proxy or an SSH or VPN tunnel.
- **OpenClaw can also run the daemon for you.** See [managed mode](/openclaw/modes/). Stop any other owner first.
- Back up both the profile and the daemon's data folder. See [Storage and backups](/how-it-works/storage/).
</Aside>
