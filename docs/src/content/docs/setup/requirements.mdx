| You need | Why |
| --- | --- |
| **A Linux machine for the daemon**: x64 or ARM64, glibc 2.36+ (Debian 12, Ubuntu 24.04 or newer) | Taking over a WeChat profile only works on Linux for now. Alpine (musl) isn't supported. |
| **An existing WeChat for Linux profile** | agent-wechat takes over the files of an account that has already logged in to WeChat for Linux. It can't create a profile from scratch yet. |
| **The WeChat app closed** | Only one program may write to the profile at a time. |
| **Your phone, logged in to the same account** | WeChat may ask you to approve the login or scan a QR code. |
| **FFmpeg and FFprobe** | Used for voice and video sends and some image previews. The Docker image includes them. |
| **Node 24.16+** | Only for the npm installer. The standalone binary doesn't need Node. |

## Where `wx` runs

| Platform | CLI | Daemon |
| --- | --- | --- |
| Linux x64 / ARM64 | Yes | Yes |
| macOS on Apple Silicon | Yes | Release candidate; can't take over a profile yet |
| Windows x64 / ARM64 | Yes | Release candidate; can't take over a profile yet |

macOS and Windows builds ship from version 1.0.0-beta.9. On those machines, the usual setup is the `wx` CLI (or OpenClaw) talking to a daemon on Linux or in Docker.

Next: [install](/setup/install/).

## What works

| Works | Not yet |
| --- | --- |
| Log in with saved device trust, phone approval or a QR code | Creating groups, inviting or removing members |
| Read local history, contacts, groups and members | Fetching history the profile never had |
| Receive new messages as they arrive | Sending stickers and very large files |
| Send text, images, files, video, voice and link cards | Profiles from WeChat for macOS or Windows |
| Download images, files, video and voice | Keeping WeChat's own search index up to date |
| Recall your own messages | Proxy support for outgoing connections |
| Mark chats read and notify your other devices | |

<Aside title="Good to know">
- OpenClaw and HTTP API clients can run on any OS, as long as they can reach the daemon.
- macOS and Windows support is new. The [platform checklist](https://github.com/thisnick/agent-wechat/blob/main/dev-notes/native-platform-acceptance.md) shows what has been tested.
- agent-wechat checks the profile's format before it writes anything, and stops if it doesn't recognize it.
- Creating a new profile, copying a profile elsewhere, and handing a profile back to the WeChat app are experimental. See the [capability checklist](https://github.com/thisnick/agent-wechat/blob/main/packages/native-client-rust/FEATURES.md) for what has been tested and how.
</Aside>
