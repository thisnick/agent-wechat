Support GPT-Live speech models for WeChat voice calls. Set `calls.voice.realtime.model` to `gpt-live-1-codex` to use the agent's ChatGPT sign-in, or to `gpt-live-1` with an OpenAI API key. GPT-Live listens while it talks, handles interruptions itself and delegates questions to the selected agent. Realtime models such as `gpt-realtime-2.1` keep working as before.
