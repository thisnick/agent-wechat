Show the desktop app and web UI in Simplified Chinese as well as English. The language follows your system by default; change it under Settings → Language or on the sign-in screen. The tray menu, notification previews and notification actions follow the same choice. A desktop settings file saved by this version cannot be opened by an older version of the desktop app.
