Add the DeepSeek Harness WeChat channel plugin: native daemon bridge with committed-live-only consumption, durable session routing and replies, admission policies (DM/group/mention, default closed), seventeen scoped WeChat tools (current-chat, owner, opt-in archive, opt-in calls) with per-step model-side visibility, media pipeline annotations, voice calls with OpenAI speech (fail-closed, opt-in, call summaries in a dedicated storage domain), and fail-soft activation.
